## 3. AI 활용 방식

| 기술 요소 | 역할 | 상세 |
|---|---|---|
| 멀티모달 AI (Gemini Vision) | 이미지 분석 | 피부 사진 → 붉은기/각질/여드름/색소침착 등 특징 추출, 구조화된 응답 생성 |
| AI Agent | 의사결정 및 도구 호출 | 분석 결과 기반 ① 건강 점수 산출 ② 유사 증상 카테고리 안내(진단 아님) ③ 심각도 높으면 카카오맵 병원 검색 도구 호출 ④ 관리 루틴 추천 |
| Long-term Memory | 개인화 및 추적 | 사용자별 촬영 이력 저장 → 시간 경과에 따른 점수 변화 그래프, "지난주 대비 개선/악화" 코칭 메시지 생성 |

필수 기술 요소 3개(AI Agent, 멀티모달 AI, Long-term Memory)를 모두 포함하여 미션 요구사항(2개 이상)을 상회 충족한다.

## 4. 기술적 접근 방식 및 선정 이유

```
[Frontend: 모바일 친화 웹 / PWA]
   폰 카메라로 사진 촬영 → 업로드
        ↓
[Backend: FastAPI]
   이미지 수신 → Gemini Vision API 호출 (피부 특징 추출)
        ↓
   Agent 로직: 점수 산출 + 카테고리 매핑 + 도구 호출 판단
        ↓
   DB 저장 (사용자별 이력) → Long-term Memory 조회 시 활용
        ↓
[배포: Render 또는 Railway]
   외부 접근 가능한 URL로 서비스 제공
```

| 기술 | 선정 이유 |
|---|---|
| Gemini (Google AI Studio) | 팀이 이전 프로젝트(AI 브랜드 아이덴티티 생성기)에서 이미지 관련 API 활용 경험 보유, 무료/저비용 티어로 프로토타입 개발에 적합 |
| FastAPI | 비동기 처리에 강해 AI API 호출 대기시간 관리에 유리, Swagger 자동 문서화 제공 |
| Render / Railway | 무료 티어로 빠른 배포 가능, GitHub 연동 CI/CD 지원 |
| SQLite → PostgreSQL 전환 가능 | 프로토타이핑 단계에서는 SQLite로 빠르게 시작, 사용자 증가 시 확장 가능한 스키마 설계 |
| 카카오맵 API | 국내 서비스 특성상 병원 검색 정확도가 높고, 무료 사용량 내에서 프로토타입 요건 충족 |

## 5. 기능 요구사항 (FR)

| ID | 기능명 | 설명 | 우선순위 |
|---|---|---|---|
| FR-01 | 사진 촬영/업로드 | 폰 카메라로 피부 부위 즉시 촬영 또는 갤러리 업로드 | Must |

| FR-03 | AI 이미지 분석 | Gemini Vision으로 붉은기·각질·여드름·색소침착 등 특징 추출 | Must |
| FR-04 | 피부 건강 점수 산출 | 분석 결과 기반 0~100점 수치화 (AI Hub 한국인 피부상태 측정 데이터의 평가 항목 체계 참고) | Must |
| FR-05 | 유사 증상 카테고리 안내 | "진단 아님" 고지 포함, 5종 패턴(건선/아토피/여드름/지루피부염/주사) 중 유사도 안내 | Must |
| FR-06 | 전문의 상담 권장 트리거 | 심각도 임계값 초과 시 "피부과 방문 권장" 메시지 + 카카오맵 병원 검색 도구 호출 | Must |
| FR-07 | 관리 루틴 코칭 메시지 | 분석 결과 기반 생활 습관/관리 팁 생성 (AI 생성 콘텐츠 명시) | Must |
| FR-08 | 이력 저장 (Long-term Memory) | 사용자별 촬영 기록·점수 DB 저장 | Must |
| FR-09 | 변화 추적 리포트 | 이전 기록 대비 점수 변화 그래프 + "지난주 대비" 코칭 메시지 | Must |
| FR-10 | 사용자 피드백 수집 | 분석 결과 만족도/의견 입력 폼 | Must |
| FR-11 | 결과 히스토리 조회 | 과거 촬영 이력 리스트/상세 조회 | Should |

## 9. AI 윤리 준수 사항 (미션 필수 요건)

### 9-1. AI 생성 콘텐츠 명시

- 모든 분석 결과 화면에 다음 문구를 상시 노출한다: **"본 결과는 AI 참고용 스크리닝이며 의료 진단이 아닙니다. 정확한 진단은 피부과 전문의와 상담하세요."**
- 건강 점수, 유사 증상 카테고리, 관리 루틴 코칭 메시지는 모두 AI가 생성한 콘텐츠임을 결과 화면에 별도 표기한다.
- "의심 질환 진단"이 아닌 "스크리닝/참고용 가이드"로 서비스 포지셔닝을 확정한다. 병명을 확정적으로 제시하지 않고, 유사 패턴 안내 + 전문의 상담 권장 문구를 항상 함께 제공한다.

### 9-2. 개인정보 수집 및 관리

- 피부 사진 및 건강 관련 정보는 민감정보로 간주하며, 촬영 전 **명시적 동의 체크박스**(FR-02)를 통해 사용자 동의를 받는다.
- 동의 화면에는 촬영 목적, 저장 기간, 삭제 방법을 명확히 안내한다.
- 사용자는 본인의 데이터를 언제든 삭제 요청할 수 있다 (FR-12).
- 저장되는 사진·건강정보는 암호화하여 보관하고, 접근 권한을 최소화한다 (NFR-02).
- 실사용자 테스트 참여자에게는 별도의 테스트 참여 동의서를 통해 데이터 수집·활용 목적을 사전 고지한다.

### 9-3. 진단 오남용 방지

- 심각도가 높다고 판단되는 경우 반드시 병원 방문을 권장하는 방향으로 Agent 로직을 설계하며, 사용자가 AI 결과만으로 병원 방문을 미루지 않도록 안내한다.
- Gemini Vision의 분석 결과는 확률적·참고적 정보이며 확정적 의학적 사실이 아님을 프롬프트 설계 및 UI 문구 양쪽에서 일관되게 전달한다.
